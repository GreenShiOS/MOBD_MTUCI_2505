# Отчеты по дисциплине МОБД (Группа БВТ2505)

В этом репозитории мы прикрепляем свои отчеты по лабораторным работам дисциплины "Математические Основы Базы Данных"

## ⚠️ Важные правила
1. **Только PDF:** Сдаем отчеты строго в формате `.pdf`. Word-файлы не принимаются.
2. **Только своя папка:** Каждый работает **только** в папке со своей фамилией. Не трогайте чужие папки!
3. **ВСЕГДА делайте `git pull` перед `git push`!** Это самое важное правило, чтобы не сломать репозиторий.

---

##  Инструкция: Как сдать отчет через терминал (Git Bash)

Если вы установили Git, открывайте Git Bash в папке, куда хотите скачать репозиторий, и выполняйте по порядку:

### 1. Скачайте репозиторий к себе (делается один раз)
```bash
git clone https://github.com/GreenShios/MOBD_MTUCI_2505
cd MOBD_MTUCI_2505
```
### 2. Обновите вручную репозиторий(ДЕЛАЕТСЯ ПЕРЕД КАЖДЫМ ПРИКРЕПЛЕНИЕМ)
```bash
git pull
```

### 3. В ручную или иным способом через проводник перенесите в скачанный репозиторий свой отчёт

### 4. Отправьте изменения на GitHub
```bash
git add .
git commit -m "Ваш комментарий"
git push
```
